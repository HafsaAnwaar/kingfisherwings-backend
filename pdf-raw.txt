APPENDIX B — DECISIONS LOCKED BEFORE DEVELOPMENT
v1 MVP Scope: Air Export + Sea FCL Export + Sea FCL Import. These 3 cover 70–80% of revenue. Air Import added Week 15. All
other modes Phase 2. UAE VAT only for v1 finance compliance.
Multi-Tenancy Architecture: Single PostgreSQL database. Every table has tenant_id UUID NOT NULL FK to tenants table.
Row-Level Security (RLS) policies enforced at database level from Week 0 — not application-level scoping added later. Prisma + SET
app.current_tenant_id approach.
Job Type Architecture: Single jobs table with job_type enum. Shared child tables (job_charges, job_milestones, job_documents,
job_notes) for all types. Mode-specific detail tables (air_job_details, sea_fcl_job_details, etc.) as FK-linked extensions. No separate
table per operation type.
Document Generation: Puppeteer server-side rendering via BullMQ background queue. No synchronous PDF in request cycle. Draft
→ Original finalize workflow. Document rights (view/preview/download/email/edit/finalize/delete/reprint) enforced server-side. All PDFs
stored in S3 with pre-signed URL delivery.
Financial Visibility: Six can_see_* boolean columns on users table (can_see_sales, can_see_cost, can_see_gp, can_see_invoices,
can_see_payments, can_see_bank_balances, can_see_ar_ap, can_see_mgmt_reports, can_see_job_pnl). Enforced at API level —
financial fields return null for users without permission. UI hides corresponding elements.
v1 Finance Compliance: UAE VAT 5% only. KSA ZATCA (requires Saudi authority certification) and India IRN e-invoicing (requires
GSTN registration) deferred to Phase 4. UAE TRN on all tax invoices. WPS payroll file for UAE.
Team Ownership: Dev 1 owns all backend (NestJS), database (PostgreSQL + RLS), infrastructure, PDF generation (Puppeteer),
queue (BullMQ), and all API endpoints. Dev 2 owns all frontend (Next.js), UI components (TailwindCSS + shadcn/ui), React Hook
Form + Zod validation, TanStack Query, and QA. No context-switching mid-week.
