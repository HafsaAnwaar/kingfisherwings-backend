What is this booking form?

This is one shared booking request for customers. Instead of a different form for every service, the customer picks the job type once, then walks through the same clear steps: service setup, shipment details, shipper and consignee, cargo, documents, and review.

Same core path

Every request collects the parties, cargo description, key documents (like commercial invoice), and a final confirmation — so compliance stays consistent across the business.

Changes by service

Sea asks for ports (POL/POD) and TEUs. Air uses airports and flight details. Land / Road / Courier use cities and door addresses. Customs / Warehouse / Service skip door-to-door scope and focus on clearance or storage needs.

Scope and documents

For transport jobs, service scope (Door to Door, Port to Port, and so on) unlocks the right pickup or delivery address fields. Cargo type also changes document needs — for example Carnet for vehicles, MSDS for dangerous goods.

Try switching job types on Step 1 — the form reshapes itself so the customer only sees what that service needs.
